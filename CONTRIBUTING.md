# Contribuindo

Use Node.js 22 ou superior. Não há instalação de dependências.

```sh
npm run dev
npm run check
npm test
npm run build
```

Abra um pull request explicando o problema, a mudança e a validação. Preserve acessibilidade, layout móvel, independência de serviços pagos e ausência de telemetria. Não inclua dados reais nos exemplos.

Mudanças em saúde exigem fonte primária, população, edição e atualização de `docs/SCIENCE.md`. Alterações em dinheiro, recorrência, backups e validação de empresa precisam de testes dos casos de borda. Novas dependências devem ter justificativa e licença compatível.
