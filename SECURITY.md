# Segurança e privacidade

MyRotine 0.1 é um app local, sem autenticação, backend ou criptografia própria. Não o apresente como prontuário, cofre financeiro ou serviço multiusuário pronto para produção.

- Não registre senhas, CVV, números completos de cartão ou prontuários.
- Quem acessa o perfil do navegador pode ler seus registros.
- Backups JSON e títulos de eventos ICS podem conter dados pessoais.
- Links externos de referências abrem em outra aba. Esses sites têm suas próprias políticas.
- Notificações usam texto genérico, para evitar expor detalhes na tela bloqueada.
- A limpeza do navegador pode apagar o armazenamento local.
- Não publique backups, registros reais ou credenciais em issues e pull requests.

Para reportar vulnerabilidades, utilize o recurso privado de segurança do repositório, caso esteja habilitado. Se não estiver, abra uma issue pedindo um canal privado sem incluir detalhes exploráveis ou dados pessoais.
